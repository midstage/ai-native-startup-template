# 8_companies: one folder per customer or partner

Customers, prospects and partners sit together, one folder each, named `company-name/`.

Each folder has a `CONTEXT.md`: the one living summary of that company. Key people, how they like to communicate, what they bought, the history of the relationship. Update it in place. Dated files next to it hold call notes, transcripts and proposals (`YYYY-MM-DD_description.md`).

Before an agent drafts anything for a company, it reads that company's `CONTEXT.md` first. Raw call transcripts, with all the hesitations left in, carry more of the relationship than a cleaned-up summary.
