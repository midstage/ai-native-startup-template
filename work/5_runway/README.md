# 5_runway: finance

- **Produces:** runway, and a return investors find compelling. Reinvests it as resources for the rest of the flywheel.
- **Receives:** paying customers from customer success (`4_success`).
- **Feeds:** back office, people and agents (`6_capacity`).
- **Put here:** budget, cash and runway, pricing economics, agent and tool spend, fundraising.
- **Agents here** never move money. Payments are one-way doors.
