# 6_capacity: back office, people and agents

- **Produces:** capacity: more people or more agents, and more output from each through systems, training and better practice.
- **Receives:** runway from finance (`5_runway`).
- **Feeds:** product and engineering (`1_marketable`), and the loop spins again.
- **Put here:** which agents exist and what number each owns, hiring, tools and accounts, company strategy.
