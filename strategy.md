# Strategy

Your plan at a glance: the decisions every agent needs to know before it acts. It runs from what never changes (your core) down to this quarter. This week's goals live in `flywheel.md`, and the jobs in `backlog.md`.

Agents read this file before they set priorities, write for a customer, or start anything new. When a job would break a decision here, the agent stops and asks. It never quietly works around it.

The flywheel interview fills this in (say `interview me on strategy`). Anything still open stays TBD. Never fill it with guesses: a made-up value or goal is worse than an honest TBD, because agents will follow it.
