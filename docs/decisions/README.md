# Decisions

One file per decision, so the reason behind the company's choices outlives the chat it was made in.

- Name: `YYYY-MM-DD_short-title.md`. Copy `_template.md`.
- Append only. Never edit a past decision. When a decision changes, write a new file that supersedes it, and add one line to the old file pointing to the new one.
- Record the alternatives you rejected and why. That is what stops the same debate from starting again next month.
